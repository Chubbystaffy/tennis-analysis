# Example output

Generated by `python analyse.py example_clips/` (after `python fetch_examples.py`).

| File | What it is |
|---|---|
| `djokovic_2012_usopen_chart.png` | per-clip chart: shoulder/hip turn, wrist speed, Sports2D angles, swings |
| `djokovic_2012_usopen_summary.txt` | per-clip text summary |
| `djokovic_2012_usopen_swings.csv` | per-clip swing table |
| `djokovic_annotated_contact.jpg` | one frame of the annotated video, at forehand contact |
| `summary_all_clips.txt`, `all_swings.csv` | combined summary over the five example clips |

The pro clips are **not** filmed the way the tool expects (side-on, fixed camera): see
"Validation on pro footage" in the main README for which numbers can be trusted.
